**Campground Explorer App** is an Android app that allows users to view a list of campgrounds, including campground name, description, location, and image, even when offline.



Time spent: **15** hours spent in total

## Required Features

The following **required** functionality is completed:

- [X] Most recently fetched data is stored locally in a database.
- [X] If user turns on airplane mode and closes and reopens app, old data from the database should be loaded.
